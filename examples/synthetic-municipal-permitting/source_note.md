# Source Note: Synthetic Municipal Permitting Signals

Date: 2026-06-11
Source: Synthetic example
Evidence maturity: Structured observation
Related theme: Local government workflow automation
Decision status: Experiment

## Why This Source Matters

The example shows how weak public or anecdotal signals should be handled. They can create a problem candidate. They cannot create conviction.

## Key Claims

- Small contractors often manage permits across multiple city portals.
- Permit delays can block project starts, inspections, and payments.
- Expediters may create value by translating city comments into next actions.

## What This Changes

- Pattern supported: fragmented public workflows create coordination pain.
- Problem suggested: contractors need a clearer permit status and resubmission workflow.
- Assumption challenged: the pain may sit with expediters, not contractors.
- Decision pressured: run discovery before building.

## Follow-Up

1. Interview contractors with 5-50 employees.
2. Interview permit expediters.
3. Observe one real resubmission workflow.
