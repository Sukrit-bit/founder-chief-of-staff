# Experiment Plan: Permit Resubmission Copilot

Date: 2026-06-11
Theme: Local government workflow automation
Problem: Permit comments are hard to convert into resubmission packages.
Evidence maturity before experiment: Problem candidate
Decision this experiment should support: Continue / Narrow / Park

## Assumption

Permit expediters spend meaningful time translating city comments into checklists, file requests, and resubmission packages.

## Test

Run a concierge workflow with 3 permit expediters.

For each one, use a sample permit comment packet. Manually turn it into:

- missing-document checklist;
- responsibility map;
- resubmission timeline;
- applicant-facing email draft.

## User

Permit expediters who handle small commercial or residential construction permits.

## Success Criteria

- 2 of 3 users say the output would save at least 30 minutes.
- 2 of 3 users ask to use it on another packet.
- At least 1 user says the workflow would reduce missed resubmission items.

## Failure Criteria

- Users already have a simple repeatable process.
- The work depends on city-specific judgment that is hard to generalize.
- Users value speed but would not pay or switch workflow.

## Expected Learning

The experiment should reveal whether the wedge is status tracking, document assembly, comment interpretation, or owner communication.

## Follow-Up Decision

Continue if the output saves time and creates a trusted next-action package.

Narrow if value exists only for one municipality or permit type.

Park if the buyer is unclear or the workflow is too bespoke.
