## Thesis Being Tested

An AI-assisted internal workflow may help a small expert team deliver vendor-risk reviews faster and more consistently.

The pilot should show whether the workflow is best as:

- a services firm;
- software for consultants;
- buyer-facing program-management software;
- a combined software-plus-services loop.

## Shared Workflow

```text
client request
-> vendor intake
-> fact matrix
-> risk review
-> expert review
-> client report
-> remediation tracker
```

## Decision Rule

Continue if the workflow repeats across customers and the AI-assisted system improves delivery without weakening expert review.

Narrow if only one module creates value.

Park if buyers like the output but do not need a system.

Kill if every engagement is bespoke.
