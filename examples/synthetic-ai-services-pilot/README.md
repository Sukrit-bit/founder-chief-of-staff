# Synthetic Example: AI Services Pilot

This is a fictional example.

It shows how Founder Research OS handles a live service pilot without pretending the pilot is already a venture thesis.

## Synthetic Setup

A founder is testing whether AI can help boutique compliance consultants deliver vendor-risk reviews faster.

Two channel partners introduce early customers.

The team delivers the work manually with an AI-assisted internal workflow.

The founder wants to learn which path is strongest:

1. AI-native services firm.
2. Software for consultants.
3. Buyer-facing program manager.
4. Combined software-plus-services loop.
