# Abstraction Guardrails

## Purpose

This system needs altitude control.

The common error is answering a project-level question from the current sprint.

## Layers

| Layer | Meaning |
|---|---|
| Project | The full Founder Chief of Staff operating system. |
| Theme | A broad arena with many possible companies. |
| Sub-arena | A narrower market or workflow cluster inside a theme. |
| Company hypothesis | A possible company direction. |
| Wedge | A first entry path. |
| Workflow | A repeated job or work product. |
| Artifact | A durable note, map, template, eval, or source record. |
| Conversation | Thinking that may or may not become project memory. |

## Rule

Before answering, identify the level.

If the current sprint is only one layer, say that. Do not let the sprint become the whole project.

## Example

Bad:

```text
This project is about municipal permitting.
```

Better:

```text
The project is a Founder Chief of Staff. Municipal permitting is a synthetic example used to show one research-to-decision route.
```
