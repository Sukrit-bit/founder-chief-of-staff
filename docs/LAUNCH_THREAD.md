## Longer Thread

1.

I open-sourced Founder Research OS.

It is a workspace for running AI-assisted startup discovery with memory, protocols, evals, and decision pressure.

2.

Most founders do not have a research problem.

They have a decision problem.

They read markets, scan companies, collect opinions, and talk to users. The hard part is deciding what to continue, narrow, test, park, pause, or kill.

3.

Most AI workflows stop too early.

They summarize an article.
They draft a memo.
They answer a question.

That is useful, but it does not create a durable research operating system.

4.

The loop I care about is:

```text
input -> artifact -> pattern -> decision queue -> experiment -> evidence -> updated context
```

Every meaningful input should create pressure on a decision.

5.

The repo includes:

- README / PRD / TECHNICAL / PROMPT;
- operating protocols;
- evidence maturity ladder;
- abstraction guardrails;
- decision queue template;
- synthetic example;
- visual explainer;
- docs audit and leak scan.

6.

The most important part is the evidence ladder.

Public research is not validation.
Patterns are not validation.
Interesting markets are not validation.

The system forces each idea to earn its next level.

7.

The second important part is the agent contract.

The agent is allowed to maintain the workspace:

- create artifacts;
- update indexes;
- run checks;
- log repeated failures;
- improve protocols.

But it is not allowed to overclaim evidence or leak private research.

8.

This is not a prompt pack.

It is an attempt to show what happens when an AI agent works inside a structured founder operating system instead of a blank chat window.

9.


10.
