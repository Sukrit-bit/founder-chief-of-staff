# Redaction Protocol

## Purpose

The public artifact should show the method, not the private edge.

## Public-Safe Material

- Folder structure.
- Operating principles.
- Agent contract.
- Evidence maturity ladder.
- Templates.
- Evaluation rubrics.
- Synthetic examples.
- Sanitized failure modes.
- Visual explanation of the operating loop.

## Private Material

- Live startup theses.
- Interview notes.
- Warm access paths.
- Names of cofounders, customers, firms, operators, investors, or advisors.
- Proprietary synthesis.
- Current right-to-win.
- Private decision logs.

## Export Rule

Before publishing:

1. Export into a separate public folder.
2. Replace real markets with synthetic or already-public examples.
3. Remove names, access paths, and private conversations.
4. Run a public-readiness eval.
5. Run the docs audit.

## Redaction Test

Ask:

```text
Would publishing this reduce the founder's edge?
```

If yes, keep it private or rewrite it as a synthetic example.
