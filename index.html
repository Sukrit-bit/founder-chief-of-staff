Why this exists

A context window is not operating memory. Search is not understanding. A failure log is not learning.

Memory with clear ownership

Named files and systems own the current facts. A disposable search index makes them easy to find without replacing them.

Only the context that matters

The system returns a small set of useful excerpts and follows declared links between them. It does not load the whole workspace.

Corrections that change the next task

A recurring mistake becomes a relevant rule, a release check and an outcome to observe. Logging the mistake is not enough.

What the repo gives you

A runnable memory and learning layer plus a broader founder workspace. Bring your own company information, decisions, relationships and tools.

Memory and learning are tested together

The public test checks whether the system finds the right sources, keeps context small, chooses the right rules and rejects known mistakes. These are fixed tests, not proof of general live reliability.

Synthetic task

A failure was logged but later repeated. Explain what must change before calling the system improved.

Required: rule + release check + later proof
1
Find
Recover the learning rule and failure evidence.
2
Limit
Keep the context within declared limits.
3
Select
Apply only the rules relevant to this task.
4
Reject
Block “it was logged, so it was learned.”
5
Accept
Pass an answer that connects the rule, the check and later proof.
6
Qualify
Call a fixed test a fixed test, not live reliability.

Start in three commands

Build the local search index, retrieve a small context bundle and run the fixed tests. No package installation is required.

git clone https://github.com/Sukrit-bit/founder-chief-of-staff.git
cd founder-chief-of-staff
	python3 runtime/cli.py rebuild
	python3 runtime/cli.py context "How should a repeated failure change the next answer?"
	python3 runtime/evaluate_runtime.py

Review the proof map or run python3 scripts/release_audit.py before trusting a release.

Built for early-stage founders

This is for the stage where product, customers, research, fundraising, relationships, and daily execution all change at once.

Built with AI, not for AI theater

The human owns judgment, taste and strategic calls. The agent maintains the workspace, preserves context, runs checks and turns corrections into better operating rules.
